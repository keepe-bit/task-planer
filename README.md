# TaskPlaner Enterprise

Модульный сервер управления заявками и задачами с автонумерацией, строгим журналом аудита, криптографически безопасной авторизацией и консольной утилитой администрирования.

---

## 1. Краткое описание

**TaskPlaner Enterprise** — система планирования и контроля исполнения производственных и сервисных заявок. Архитектура построена на модульном разделении уровней данных, безопасности, бизнес-логики и интерфейса:

- **Параметры задачи**: название, описание, уникальный номер (автосчетчик `номер/месяц-год`, например `001/11-2026`), статус выполнения («Новая», «В работе», «На проверке», «Выполнена», «Отменена»), назначенный исполнитель и приоритетность («Низкий», «Средний», «Высокий», «Критический»).
- **Безопасность авторизации**:
  - Хэширование паролей по стандарту **OWASP PBKDF2-HMAC-SHA256** (600 000 итераций, уникальная 32-байтовая криптографическая соль для каждой записи).
  - Сверка хэшей защищена от timing-атак с использованием константного времени `hmac.compare_digest`.
  - Сессионные токены (`secrets.token_hex(32)`) с ограниченным временем жизни (TTL 24ч) и автоматической инвалидацией при блокировке или смене пароля.
- **Журнал аудита (Audit Trail)**:
  - Неизменяемая фиксация всех операций (создание, смена статуса, редактирование полей, блокировка/удаление пользователей, входы в систему).
  - Каждая запись содержит точную метку времени UTC, логин и роль оператора, номер заявки и детальный diff изменений.
- **Ролевая модель доступа**:
  - **Пользователь (User)**: просмотр заявок, редактирование статуса, названия и описания, просмотр истории аудита по задаче.
  - **Администратор (Admin)**: создание новых заявок, изменение приоритетов и исполнителей, полный аудит системы, управление пользователями и доступ к CLI.

## 3. Команда, чтобы запустить сервер

Для запуска требуется **Node.js 18+** и **Python 3.10+**.

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки (Dev Server)
Команда запускает Express-сервер на порту **3000**, который автоматически поднимает модульный Python REST API (`backend/server.py`) на порту **5050** и монтирует интерфейс Vite SPA:

```bash
npm run dev
```

### Запуск в режиме продакшн (Production)
```bash
npm run build
npm start
```

После запуска веб-интерфейс доступен в браузере по адресу: **http://localhost:3000**

> **Важно**: Порт **5050** — это внутренний порт Python REST API. Пользователи и администраторы открывают в браузере именно порт **3000** (`http://localhost:3000`). Все запросы к `/api/*` автоматически проксируются с порта 3000 на порт 5050.
> 
> **Для пользователей Windows**: убедитесь, что при установке Python была отмечена галочка *"Add python.exe to PATH"*. На Windows в терминале вместо `python3` используется команда `python` (например, `python cli.py user list`).

## 4. Консольная утилита администрирования (`cli.py`)

Утилита командной строки позволяет системному администратору управлять учетными записями, правами доступа, блокировками, паролями и просматривать журнал аудита напрямую из терминала (или через вкладку **«CLI Консоль»** в веб-интерфейсе).

### Инициализация базы данных
Создает таблицы и наполняет начальными системными записями при первом запуске:
```bash
python3 cli.py init-db
```

### Управление пользователями (`user`)

- **Создать пользователя**:
  ```bash
  python3 cli.py user add <логин> <пароль> [--role admin|user] [--name "ФИО"]
  ```
  *Пример:*
  ```bash
  python3 cli.py user add ivanov SecretPass123! --role user --name "Иван Иванов"
  ```

- **Список всех пользователей**:
  ```bash
  python3 cli.py user list
  ```

- **Заблокировать пользователя** (мгновенно отзывает все активные сессии):
  ```bash
  python3 cli.py user block ivanov
  ```

- **Разблокировать пользователя**:
  ```bash
  python3 cli.py user unblock ivanov
  ```

- **Изменить роль пользователя** (`admin` или `user`):
  ```bash
  python3 cli.py user set-role ivanov admin
  ```

- **Сбросить пароль пользователя**:
  ```bash
  python3 cli.py user reset-password ivanov NewSecurePass2026!
  ```

- **Удалить пользователя**:
  ```bash
  python3 cli.py user delete ivanov
  ```

### Просмотр заявок (`task`)
```bash
python3 cli.py task list
python3 cli.py task list --status in_progress
```

### Просмотр журнала аудита (`audit`)
```bash
python3 cli.py audit list --limit 20
```

## 5. Описание, как зайти в систему

1. Откройте веб-браузер и перейдите по адресу:
   ```
   http://localhost:3000
   ```
2. В окне авторизации введите логин и пароль. Для быстрого тестирования доступны предустановленные учетные записи:

| Роль | Логин | Пароль | Доступные разделы и действия |
|---|---|---|---|
| **Администратор** | `admin` | `AdminPass123!` | Полный доступ: вкладки «Заявки», «Журнал аудита», «Пользователи», «CLI Консоль». Создание заявок, изменение всех полей, блокировка и сброс паролей. |
| **Оператор (User)** | `operator` | `UserPass123!` | Вкладки «Заявки» и «Журнал аудита». Просмотр заявок, изменение статуса выполнения, редактирование названия и описания, просмотр аудита. |
| **Инженер (User)** | `analyst` | `UserPass123!` | Доступ оператора к распределенным задачам. |

3. Нажмите кнопку **«Войти в систему»** (или кликните по карточке быстрой подстановки учетных данных в форме).
